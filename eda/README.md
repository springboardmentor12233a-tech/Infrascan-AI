# InfraScan EDA Module

Exploratory Data Analysis scripts and verified audit reports for the RDD2022 road damage dataset.

## Structure
- `scripts/` — `dataset_audit.py`, `dataset_audit_backup.py`
- `reports/` — Verified CSV summaries (`class_distribution.csv`, `country_summary.csv`, `dataset_preparation_summary.csv`, etc.)
- `notebooks/` — Jupyter notebooks (for future interactive analysis)
- `visualizations/` — Generated charts and plots

## Verified Dataset Summary
- 38,385 image/annotation pairs
- 65,711 valid bounding boxes
- 1 invalid bounding-box object excluded
- 11,724 candidate negative annotations
